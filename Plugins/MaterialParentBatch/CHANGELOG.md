# 更新记录

## 1.1.0

- 整理为独立插件，默认副本目录改为 `/Game/MaterialParentBatch/Variants`。
- UE 5.5/5.6 和 5.7/5.8 分别使用对应材质参数头文件，避免新版弃用入口。
- 提供各 UE 版本的隔离构建与自动化测试脚本，使用对应引擎的编译设置。
- 源码允许按不同引擎编译；各引擎版本单独发布 Win64 编译包。

## 1.0.0

- 从所选静态模型、骨骼模型、材质实例或关卡 Actor 收集并去重。
- 支持修改原实例、复制实例后替换所选目标。
- 提供参数兼容预检、过期预览校验、磁盘备份和编辑器撤销。
- 提供中文操作面板及六项自动化测试。
