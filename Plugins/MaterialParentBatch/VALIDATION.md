## 验证方法

`Scripts/BuildAndTest.ps1` 使用指定引擎，在独立的临时工程中构建插件。目标使用该引擎的最新编译和头文件顺序默认设置，关闭 Unity 合并编译以检查每个源文件的依赖。

测试以 DX12 离屏编辑器运行，要求下列六项均为 Success，失败、未运行和运行中计数均为零。没有打开、升级、保存或替换原游戏工程的资产。

| 自动化测试 | 验证内容 |
| --- | --- |
| ActorCopyAndUndo | 所选 Actor 组件复制替换、共享槽位去重、整批撤销 |
| CollectionAndAssignment | 静态和骨骼模型收集、去重、材质槽赋值 |
| DuplicateExecution | 新实例复制、保留原实例及参数覆盖 |
| EditorPanel | 菜单对应的编辑器面板创建 |
| ParentAndParameters | 同名同类型参数覆盖、循环父级拦截、反复替换和撤销 |
| PreviewAndStaleGuard | 预览不修改资产、过期状态拒绝执行、输出目录校验 |

## 环境问题与处理

- 较新 UE 不允许隔离目标使用与已安装编辑器不同的旧编译默认值；脚本按所选引擎使用 Latest 默认设置。
- UE 5.5 对文件系统 DDC 根路径有限长要求；脚本仅在隔离测试工程中配置短缓存路径，不修改引擎或用户的全局配置。
- UE 5.5 的两组测试带引擎资源警告：28 条缺失 Slate 图标警告、1 条 Water 控制台变量查询性能警告。对应测试仍为 Success，没有测试断言失败；未屏蔽这些警告。

## 记录与验证边界

构建输出保存在 `Artifacts/UE_实际版本/`：`Build.log`、`Automation.log`、`TestReport/index.json`、`Result.json`。发布包中的 `BUILD_INFO.json` 记录对应构建结果，`SHA256SUMS.json` 用于核对文件完整性。

实测针对各表列明的引擎补丁版本、Win64 编辑器和测试资产，不表示已在其他平台或所有游戏资产组合上验收。不同引擎构建号可能需要重新编译。

Material Layers、Curve Atlas 参数和参数重命名映射暂不支持，预检会拦截相关情况。替换父级仍可能因着色逻辑或继承默认值变化而改变外观。

磁盘备份只保留已保存的包文件，操作前已有的未保存状态依赖编辑器撤销。撤销后新副本可能保留。
